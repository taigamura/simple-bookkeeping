# Cat companion mockups

Throwaway UI prototype answering: **where should a RunCat-like bookkeeping companion live, and how much attention should it ask for?**

Open [`cat-companion.html`](./cat-companion.html) directly in a browser. Use the bottom switcher (or the left/right arrow keys) to compare:

- **A — Header Cat:** a tiny, ambient companion that stays out of the bookkeeping UI.
- **B — Mochi's Corner:** a more expressive habitat card with feeding progress.
- **C — Entry Streak:** a competitive, streak-led treatment where the cat runs along the month.

In every variant, press **Log an entry** to preview the `purr → fed` reward. The state controls also expose sleep, run, purr, and fed poses.

The chosen direction and rationale should replace this paragraph before the prototype is deleted or promoted.

# Light direction studies

[`light-directions.html`](./light-directions.html) — five ways to merge
[@nemuiasaa](https://x.com/nemuiasaa)'s off-white/one-mark aesthetic with
mokumono's electric blue and uppercase mono. Reference material lives in
`docs/references/`. Open the file directly in a browser; each direction shows
Summary, Calendar and the Entry sheet, plus an app-icon concept, palette, and
a keeps/costs note.

| # | Direction | Ratio | In one line |
|---|-----------|-------|-------------|
| 1 | Shirokane 白金 | mostly nemuiasaa | Sans everywhere, blue used four times a screen. The quietest. |
| 2 | Blueprint 図面 | mostly mokumono | No cards — hairlines, dotted leaders, all-caps mono. A technical drawing. |
| 3 | Kaji Blue 家事青 | even | Today's token system with the lights on. Cheapest to ship. |
| 4 | Yohaku 余白 | nemuiasaa (hibi) | Warm paper, no fills, one small blue square. Editorial. |
| 5 | **Kippu 切符** ← chosen | nemuiasaa (ondot) | One saturated blue block + pills as the whole interaction language. |

**Chosen: 5 — Kippu 切符**, on the strength of the direction and the app mark.
Refinement continues in Claude Design (`Kaji — Kippu 切符` project), where the
port lives as a design canvas with per-screen comment anchors. This file stays
as the record of the five-way comparison.
